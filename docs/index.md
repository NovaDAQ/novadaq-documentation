# NOvA DAQ documentation

This suite covers all **120 repositories** in the reviewed `novadaq-pkgs` workspace. It connects package references, source evidence, operating procedures, and the code-review issue register.

- **Decide what to fix:** [severity-ranked remediation priorities](review/index.md).
- **Find a component:** [package catalog](packages/index.md), with purpose, entry points, interfaces, configuration, tests, and operating notes for every package.
- **Understand change impact:** [system architecture](architecture/index.md), [dependency diagrams](architecture/dependencies.md), and the [interactive dependency explorer](architecture/explorer.md).
- **Operate or recover DAQ:** [operations runbook](operations/index.md), [build/release guide](operations/build.md), and [failure recovery](operations/recovery.md).
- **Assess the evidence:** [review coverage](review/coverage.md), [methodology](review/methodology.md), and [reviewed revisions](review/snapshot.md).

The source snapshot is dated **2026-09-30**. Source links use exact commits. Deployment topology, active release, package ownership, and retirement decisions have not been confirmed against a running detector. Operational steps below are source-derived procedures to reconcile with the site's current configuration.

The documentation can be read directly as Markdown on GitHub or built as a searchable local site. See [maintaining this suite](contributing.md).
